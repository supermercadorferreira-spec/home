Supermercado R Ferreira - Site Institucional
------------------------------------------
Localização: Coribe-BA
Contato: supermercadorferreira@gmail.com

Instruções de Uso:
1. Extraia todos os arquivos desta pasta.
2. Certifique-se de que os arquivos 'index.html', 'style.css' e 'script.js' estejam na mesma pasta.
3. Clique duas vezes em 'index.html' para abrir o site no seu navegador.

Para colocar o site na internet:
1. Registre um domínio (ex: www.supermercadorferreira.com.br).
2. Contrate um serviço de hospedagem.
3. Faça o upload destes arquivos para a pasta pública do seu servidor (geralmente public_html).
